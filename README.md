# 家庭財務實驗室

第一版 Python Streamlit Dashboard，以繁體中文展示家庭收支、未來 60 個月現金流，以及股票持倉與未實現盈虧。介面以窄螢幕為起點，採單欄主版面、每列最多兩個指標及可橫向滑動的表格。

**全部收支、股價、持倉及匯率均為虛構示範，並非即時行情或投資建議。應用程式不連接銀行、券商或行情 API，不需要 API 金鑰。**

## 本機啟動

建議使用 Python 3.12。於此 repository 根目錄執行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1 --server.headless true --browser.gatherUsageStats false
```

預設連接埠為 `8501`。以上只啟動本機服務，沒有公開部署。每次新終端機請重新啟用虛擬環境。雲端任務可直接使用既有 checkout，無需另外建立 Git worktree。

`.streamlit/config.toml` 設定了配色、本機綁定及停用 Streamlit 使用統計。

## 功能

- **財務總覽**：每月收入、支出、結餘、儲蓄率、現金可支應月數、股票市值與未實現盈虧。
- **家庭收支**：編輯、新增、刪除每月收入及支出項目，顯示支出分佈並下載 CSV。示範收入為 HK$60,000、支出 HK$39,800、結餘 HK$20,200。
- **60 個月預測**：調整開始月份、起始現金、收入／支出年增長率、現金年回報率；顯示現金曲線、首次資金缺口月份及每月明細，支援 CSV 匯出。
- **股票持倉**：編輯股票代號、示範名稱、幣別、股數、每股成本及示範股價；支援 HKD、USD 與小數股，計算各股和整體成本、市值、盈虧及回報率，支援 CSV 匯出。

所有彙總金額以港元顯示。股票代號只供識別，**不會下載該股票的真實價格**。示範美元兌港元匯率為 7.8，可自行調整。表格在手機上可左右滑動，點選列選取區可刪除項目，底部空白列可新增項目。

## 計算口徑

- 每月結餘 = 收入 − 支出；儲蓄率 = 結餘 ÷ 收入，零收入時顯示「不適用」。輸入金額須為非負有限數字，股票股數須大於零；清倉時刪除持倉列。
- 預測包含開始月份及其後 59 個月。首 12 個月使用基礎收支，第 13、25、37、49 個月各按年增長率複利調整；不是按曆年一月調整。
- 月回報率 = `(1 + 年回報率) ** (1/12) - 1`；月利息按正數期初現金計算，收支在月底入賬。
- 期末現金 = 期初現金 + 收入 − 支出 + 月利息。負數代表未補足的資金缺口，負數現金不獲利息，亦未模擬借貸成本。
- 儲備參考線固定為目前每月支出的六倍；可支應月數 = 起始現金 ÷ 目前每月支出，零支出時顯示「不適用」。
- 股票成本 = 股數 × 每股成本 × 換算匯率；市值 = 股數 × 示範股價 × 換算匯率；未實現盈虧 = 市值 − 成本。
- 組合回報率 = 總盈虧 ÷ 總成本，按成本加權，並非各股回報率的簡單平均；零成本時不提供回報百分比。CSV 中回報率以小數表示，例如 `0.1` 代表 `10%`。
- 成本和市值使用同一匯率，未計匯兌損益、股息、稅項及交易費用。股票市值及交易不會自動流入現金預測。
- 「現金與股票合計」只加總起始現金與股票市值，未扣除負債，不能視作完整淨資產。

## 資料與限制

示範資料位於 `demo_data.py`。編輯結果只保留於目前 Streamlit 瀏覽器連線的記憶體；重新載入或結束連線可能重設，未使用資料庫或寫回示範檔案。可下載含 UTF-8 BOM 的 CSV，方便以試算表開啟。

第一版未包含登入、跨連線儲存、銀行匯入、即時行情、交易紀錄、已實現盈虧、買賣手續費、負債管理或隨機情境模擬。收入及支出均為每月預算，若需要反映稅款、股息或固定還款，可自行在家庭收支加入相應項目。手機介面採響應式排版；Streamlit 內建選單及表格工具列可能包含英文。

## 測試

在已啟用虛擬環境的 repository 根目錄執行：

```bash
python -m pytest -q
```

- `tests/test_finance.py`：收支彙總、零收入、60 個月月序、增長時點、現金複利、資金缺口、港美元換算、加權回報、空持倉及無效輸入。
- `tests/test_app.py`：使用 Streamlit `AppTest` 執行實際頁面，驗證分頁、預設數字、修改假設與表格後重新計算、空資料及輸入錯誤處理。此為程式層級測試，不等同實體手機瀏覽器視覺測試。

## 檔案

```text
app.py                 Streamlit 介面及 CSV 匯出
finance.py             不依賴介面的財務計算
demo_data.py           虛構示範資料
requirements.txt       已固定版本的直接依賴，包含測試工具
.streamlit/config.toml  介面配色與本機服務設定
tests/test_finance.py  財務計算測試
tests/test_app.py      Streamlit 互動測試
```
